About Foundation for Community Language and Arts

Foundation for Community Language and Arts supports inclusive language education, creative expression, and community-based arts programming.

FCLA is built around a simple idea: language access and cultural expression help people participate more fully in community life. The organization brings together learners, families, artists, educators, and volunteers through programs that value local knowledge and shared creativity.

What FCLA Supports

  • Practical language learning for everyday communication.
  • Arts education that invites storytelling, making, performance, and reflection.
  • Multilingual resources that make community programs easier to navigate.
  • Cultural programming that respects the people and places it serves.

Static Site Architecture

This website is a frontend-only Astro site with React components where interactivity is needed. Pages are generated as static HTML, CSS, and JavaScript so the output can later be published safely to GitHub Pages.

The contact page does not submit to a local API route. Form submission will remain disabled until FCLA selects an external backend that can handle validation, spam prevention, delivery, and storage.
