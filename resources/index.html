Resources

This page collects static, public-facing resource areas for Foundation for Community Language and Arts.

For Learners

Language programs focus on confidence, everyday communication, and respectful participation. Future resource updates can include learning guides, program schedules, accessibility notes, and multilingual handouts.

For Artists and Educators

Arts education resources can support workshops, classroom activities, community storytelling, and cultural programming. Materials should be reviewed for accessibility and cultural fit before publication.

For Volunteers

Volunteer-facing materials should be safe to publish publicly. Private rosters, phone numbers, email lists, background-check details, and internal logistics should stay out of the static site.

Publishing Note

Only generated files from .static-pages/ should be copied to a public GitHub Pages repository. Source files, lockfiles, environment files, and private repository history should not be published.
