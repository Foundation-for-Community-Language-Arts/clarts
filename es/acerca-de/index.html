Acerca de Foundation for Community Language and Arts

Foundation for Community Language and Arts apoya la educación lingüística inclusiva, la expresión creativa y los programas artísticos basados en la comunidad.

FCLA parte de una idea sencilla: el acceso lingüístico y la expresión cultural ayudan a las personas a participar más plenamente en la vida comunitaria. La organización reúne a estudiantes, familias, artistas, educadores y voluntarios mediante programas que valoran el conocimiento local y la creatividad compartida.

Qué apoya FCLA

  • Aprendizaje práctico de idiomas para la comunicación cotidiana.
  • Educación artística que invita a narrar, crear, presentar y reflexionar.
  • Recursos multilingües que facilitan el acceso a programas comunitarios.
  • Programas culturales que respetan a las personas y los lugares a los que sirven.

Arquitectura del sitio estático

Este sitio web es un proyecto Astro exclusivamente frontend con componentes React donde se necesita interactividad. Las páginas se generan como HTML, CSS y JavaScript estáticos, por lo que el resultado puede publicarse más adelante de forma segura en GitHub Pages.

La página de contacto no envía datos a una ruta API local. El envío del formulario permanecerá deshabilitado hasta que FCLA seleccione un sistema externo para validación, prevención de spam, entrega y almacenamiento.
