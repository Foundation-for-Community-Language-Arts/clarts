Actualización del formulario de contacto para el sitio estático

FCLA Team

Foundation for Community Language and Arts

Mar 5, 2026

Por qué el formulario está deshabilitado

Este sitio web está diseñado como un sitio estático exclusivamente frontend. Eso mantiene el artefacto público simple y seguro de publicar, pero también significa que GitHub Pages no puede ejecutar un endpoint privado de servidor para mensajes de contacto.

Hasta que FCLA seleccione un sistema externo para formularios, el formulario de contacto permanecerá deshabilitado. No se envían nombres, correos electrónicos ni mensajes a una ruta API local.

Requisitos del backend

Cualquier backend de contacto futuro debe proporcionar validación del lado del servidor, prevención de spam, entrega segura y controles de almacenamiento. Los secretos y las credenciales privadas deben quedar fuera del código frontend.
